## 🌟 核心功能

### 📚 智能高亮与翻译

| 功能 | 说明 |
| :--- | :--- |
| **多词高亮** | 生词显示为蓝色，熟词显示为黄色，一目了然 |
| **单词爆炸** | 一次查询多个生词，并通过 AI 翻译完整句子 |
| **单词笔记** | 记录自己的理解，建立个性化学习笔记 |
| **AI 推荐笔记** | 精准易懂地分析句子 |
| **AI 例句分析** | 继续追问，深入理解单词用法 |
| **例句记录** | 保存重要句子，随时复习 |
| **自定义外部按钮** | 一键查询词典和百科 |

### 🌍 跨平台支持

| 使用场景 | 支持情况 |
| :--- | :--- |
| 浏览器 | Chrome、Edge 和 Firefox 扩展 |
| 移动端 | iOS 和 Android |
| 同步 | WebDAV 或免费的 Docker 自托管同步 |
| 阅读 | Readest 及其他 EPUB 网页阅读器 |
| PDF | 支持 Mozilla PDF 阅读器 |

### 🎯 更多实用功能

#### YouTube 字幕增强

- **字幕控制**：灵活控制字幕显示与隐藏
- **AI 修复**：智能修复缺少标点的英文字幕
- **高亮支持**：兼容 Trancy 等插件

#### 阅读辅助

- **仿生阅读**：提升阅读速度和理解能力
- **简悦模式**：在专注阅读环境中提供高亮支持
- **液态玻璃弹窗**：优雅的界面交互

#### 文本转语音

- **自定义 URL**：灵活配置 TTS 服务
- **Edge TTS**：高质量语音合成
- **Minimax TTS**：丰富多样的音色选择
